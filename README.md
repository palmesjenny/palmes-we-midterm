
#  Petal & Pearl | Floral Boutique

Welcome to **Petal & Pearl**, a beautiful floral boutique website featuring elegant flower bouquets for every special occasion.

##  About the Project

Petal & Pearl is a floral boutique website designed to showcase beautiful flower arrangements. It provides visitors with an elegant and simple way to explore flower collections and contact the shop.

##  Features

- Home section with a welcome message
- Flower collection with product images
- Bouquet names and prices
- About Us section
- Contact information
- Light Mode and Dark Mode toggle
- WhatsApp ordering functionality
- Responsive website design
- Smooth scrolling navigation

##  Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
  - DM Sans
  - Playfair Display
